# Code of Conduct

We are committed to a welcoming, harassment-free project for everyone.

Be respectful, assume good intent, critique ideas rather than people, and protect private or sensitive information. Harassment, discrimination, threats and publishing another person's private information are not acceptable.

Report unacceptable behavior privately to the repository owner through the security contact on the GitHub profile. Maintainers may remove content or restrict participation when necessary to protect the community.
